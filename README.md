# MapViewer

MapViewer is in an interactive application to work with geographical features. This is a work in progress with more features to come as I explore the area of geospatial UI further. This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.1.4.

The project is hosted on Netlify and can be viewed on [https://mapviewerdemo.netlify.app/](https://mapviewerdemo.netlify.app/).

## Running the application

Clone the Github repo into your projects directory and `cd` into it.

```bash
git clone https://github.com/anniechakraborty/map-viewer.git
cd map-viewer
```

Inside this `map-viewer` directory, install the necessary packages by running `npm install`.

```bash
npm install       # or, npm i
```

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`.
